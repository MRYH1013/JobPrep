# 0.6.0 内容修订范围

本轮修订前端与 Java 后端各 42 题，在保留稳定 ID 和原有核心答案的基础上，增加独立工作场景、展开分析与每题三项自查点，部分增加代码/SQL 示例。总题量不变。

这些是编辑原创练习和示意代码，不是企业官方题，也不是可直接部署的完整方案。自查项用于个人复盘，不代表统一的招聘评分标准。

修订中对若干关键技术边界参考以下官方文档进行了核对：

- [React：Effect 的同步与清理](https://react.dev/learn/synchronizing-with-effects)
- [Spring：代理式事务与内部调用](https://docs.spring.io/spring-framework/reference/data-access/transaction/declarative/annotations.html)
- [Java 21：ThreadPoolExecutor](https://docs.oracle.com/en/java/javase/21/docs/api/java.base/java/util/concurrent/ThreadPoolExecutor.html)

上述核对不代表已对每道题、全部版本或每句解析完成独立验证，也不等于领域专家审查。涉及数据库隔离行为、框架模式和运行时版本的回答，应在实际目标环境进一步复现。

其他岗位仍以专题任务为主，待后续逐岗位增加独立题干、完整案例、验证证据和专业评审。现有数量覆盖报告只证明题目数量和结构，不证明正确性或内容深度。
