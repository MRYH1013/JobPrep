# JobPrep v0.6.1

首个公开 Windows 桌面发行版：离线练习、无需账号、不接入 AI。

## 下载与安装

- **安装版**：下载 `JobPrep-0.6.1-windows-x64-setup.exe`，按向导安装。
- **解压版**：下载 `JobPrep-0.6.1-windows-x64.zip`，完整解压后运行 `JobPrep.exe`，不要只拷出 exe。
- **校验**：下载 `SHA256SUMS.txt`，在 PowerShell 中运行 `Get-FileHash -Algorithm SHA256 '下载文件路径'`，与对应文件校验值比较。

安装包目前未做代码签名，仅提供 Windows x64 构建。macOS、Linux、Windows ARM64 尚未完成发行测试。

## 包含功能

- 20 个职业方向、120 个细分岗位，每岗位 42 道，另含通用问答 100 条，共 5,140 道练习。
- 职业方向 → 细分岗位 → 先作答 → 对照解析，进度按细分岗位统计。
- 收藏范围、自查、需复习与到期复习、继续上次学习。
- JSON 备份导出、预览和合并恢复，兼容历史记录。
- 离线计时模拟面试、逐题复盘、阅读设置与题目纠错文件导出。
- 前端与 Java 后端共 84 道增加场景与展开分析，8 道补充代码或 SQL 示例。
- 修复掌握、收藏、需复习按钮导致答题页面抽动的问题，保留滚动位置与展开状态。

## 内容与数据说明

题目为编辑原创练习，不声称是企业真题或经统计的高频题；不少岗位仍采用专题任务结构，尚未经过领域专家逐题审查。学习记录只保存在本机，软件不提供云同步；换设备或重装前请先导出记录。
